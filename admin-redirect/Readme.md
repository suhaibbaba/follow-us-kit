Create a Custom Plugin

1. Connect to your server via FTP, SFTP, or file manager
2. Navigate to: /wp-content/plugins/
3. Create a new folder: admin-redirect
4. Inside that folder, create a file: admin-redirect.php
5. Paste the code from the artifact into that file
6. Save the file
7. Go to WordPress Admin → Plugins
8. Activate "Admin Only Access - Nginx Redirect"
9. Clear Cache for wordpress
